# Architecture Decisions

## ADR-001 — Original UI, Matrix protocol
Status: accepted. Relay will build original product/UI code rather than repainting Element X.

## ADR-002 — Do not invent cryptography
Status: accepted. Relay will use established Matrix SDK encryption implementations and platform secure storage.

## ADR-003 — Fair appeals are free
Status: accepted. Account restriction explanations and appeals are not premium-gated.

## ADR-004 — Phone number is not identity
Status: accepted. Users have stable account IDs and public handles. Phone numbers are optional, replaceable attributes.

## ADR-005 — Low-data behavior is core
Status: accepted. Low Data Mode is part of the free product baseline.
