# Known Limitations

1. The current web client is a UX prototype using local sample data.
2. Real Matrix SDK integration has not yet been completed.
3. The development homeserver has not yet been validated from GitHub CI.
4. Android and iOS applications have not yet been compiled.
5. E2EE has not yet passed the two-account milestone.
6. Calling is not yet integrated.
7. No physical mobile-device testing has been performed.
8. Production legal review of third-party licenses remains required.
