# Privacy Product Rules

Free users receive baseline security, block/report controls, phone-number visibility, device/session controls, and appeal access.

Premium may add convenience features but must not remove baseline security from free users.

## Privacy Profiles
Built-in templates:
- Friends
- Work
- Public
- Invisible

Profiles may control only settings actually supported by the client/protocol, including phone visibility, presence, typing/read indicators, calls, group invites, and message-request behavior.
